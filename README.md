# 崩坏：星穹铁道抽卡概率分析器

一个在自己电脑上运行的抽卡记录管理工具，用来保存不同账号的抽卡历史，查看垫池、五星结果和个人统计，方便查阅和备份。

获取新记录时需要联网，查看已保存的记录可以离线进行。

## 主要功能

- 通过抽卡记录链接获取记录，也能导入 JSON、CSV。
- 按 UID 保存账号历史，更新时自动合并、去重。
- 支持切换账号，重新打开时恢复上次查看的账号。
- 可以切换为匿名初始数据，隐藏当前账号信息。模拟记录不含真实角色名和光锥名。
- 分别查看角色活动、光锥活动、常驻和新手跃迁。
- 显示当前垫池、五星历史、出金抽数及“歪”“保底”徽章。
- 查看各卡池抽数、星级占比，导出 CSV、JSON 或 Excel。

## 运行程序

需要 Python 3.11 或更高版本。Windows 版 Python 通常自带 Tkinter 窗口组件。

下载项目并进入项目文件夹，执行：

```powershell
pip install -r requirements.txt
python app.py
```

打包为 Windows 程序：

```powershell
.\build_exe.ps1
```

生成的文件是 `dist\HSR-Gacha-Analyzer.exe`，运行它不需要另外安装 Python。

## 使用方法

1. 点击输入框旁的“获取教程”，按照说明获取自己账号的抽卡记录链接。
2. 粘贴链接，点击“从 API 获取 / 更新”。
3. 程序按 UID 保存记录，并与该账号已有历史合并。
4. 在“账号概览”选择账号，在各个页签查看记录。
5. 需要备份时，点击左侧的导出按钮。

链接格式示例（凭据只是占位符）：

```text
https://public-operation-hkrpg.mihoyo.com/common/hkrpg_gacha_record/api/getGachaLog?authkey=<YOUR_AUTHKEY>&page=1&size=20&gacha_type=11&end_id=0
```

程序逐页获取记录，请求之间稍作等待。网络出错时会重试；链接过期时请重新获取。

## 抽卡状态怎么看

角色活动池和光锥活动池各自计算状态，互不影响。程序按时间顺序读取五星记录，使用下面的规则：

```text
普通状态
   │
   ├── 出 UP ───────────→ 普通状态
   │
   └── 歪 ──────────────→ 大保底状态
                              │
                              └── 下一金必 UP
                                      │
                                      ↓
                                  普通状态
```

界面里的“小保底”表示上图的普通状态。“歪”显示红色徽章，大保底获得的 UP 显示“保底”徽章。常驻池和新手池不使用这套状态，也不会显示这些徽章。

“当前垫池”是最近一次五星之后已抽的次数；“出金抽数”是两次五星之间的抽数。低于 70 抽显示绿色，达到 70 抽显示红色。这只是方便阅读的颜色区分，不代表出金预测。

个人 UP 成功率 = 普通状态出 UP 的次数 ÷（普通状态出 UP 的次数 + 歪的次数）。大保底获得的 UP 不参与计算。这是自己已有记录的统计，不代表下一次抽卡的概率。

历史不完整时，最早一次出金的抽数和起点状态可能不准确，请结合实际记录查看。

### 如何判断“歪”

记录通常不直接说明某个五星是不是当期 UP，因此需要配合名单判断：

- 已配置当期 UP 的卡池，优先按该配置判断。
- 角色活动池中的常驻五星，以及额外名单中的银狼、希儿、符玄、云璃、刃、银枝，标为“歪”。
- 光锥活动池中的常驻五星光锥标为“歪”。
- 其他活动池五星目前按 UP 处理。

名单保存在 `config/banner_data.json`。目前缺少完整的历期 UP 名单，也无法从记录中得知账号实际自选了哪些角色，所以可能误判。例如上述六名角色如果是当期 UP，需要补充对应卡池的配置。最终以游戏内跃迁详情和实际记录为准。

## 数据保存与备份

账号记录保存在 `%LOCALAPPDATA%\HSRGachaAnalyzer\accounts\`，程序会记住上次选择的账号。切换到初始数据只会隐藏当前显示的信息，不会删除已保存的历史。

抽卡链接中的 `authkey` 是临时访问凭据。程序不会把链接或凭据保存到账号历史和导出文件中，获取结束后会清空链接输入框。请不要公开完整链接。

Excel 包含账号汇总、全部抽卡记录和五星记录三个工作表。导出的真实记录包含 UID 等账号信息，请自行保管并定期备份。

## 项目结构

```text
app.py                       桌面界面
config/                      卡池设置和五星名单
data/sample_gacha.json       匿名模拟记录
src/api_client.py            获取抽卡记录
src/parser.py                整理、去重和排序
src/pity.py                  计算垫池和大保底状态
src/analyzer.py              汇总个人统计
src/storage.py               按 UID 保存和合并历史
src/exporter.py              导出文件
scripts/                     生成模拟数据的脚本
tests/                       自动测试
requirements.txt             运行依赖
requirements-dev.txt         测试和打包依赖
build_exe.ps1                Windows 打包脚本
hsr_gacha_analyzer.spec      打包设置
```

记录处理过程：获取或导入 → 整理和去重 → 计算抽卡状态 → 显示统计 → 保存或导出。

界面使用 Tkinter，数据整理使用 pandas，图表使用 Matplotlib。获取记录在后台进行，避免等待网络时窗口卡住。卡池和名单单独保存，方便调整。

## 检查程序

```powershell

python app.py --smoke-test
```

测试检查状态转换、卡池独立计算、记录去重、多账号保存和文件导出。最后一条命令会加载示例数据、创建窗口，然后退出。

## 目前的不足和后续计划

- 获取不到的旧记录无法自动补回，建议定期更新和备份。
- 数据仅保存在当前电脑，暂时没有云同步。
- 五星使用文字卡片，暂时没有角色和光锥图片。
- 打包主要面向 Windows，其他系统需要单独检查和打包。
- 后续希望补全历期 UP 名单，支持设置账号自选角色、历史起点状态和账号备注。
